# 🔊 Text-To-Speech (TTS) Project

## 📌 Project Overview
This project converts user entered text into speech using Python.

The system takes text input and generates voice output in MP3 format.

---

## 🎯 Objective
✅ Convert text into audio  
✅ Generate speech automatically  
✅ Save audio as MP3 file  
✅ Provide configurable voice output

---

## 🛠️ Technologies Used

- 🐍 Python
- 🔊 gTTS (Google Text-To-Speech)
- ▶️ playsound

---

## 📂 Project Structure

```bash
TEXT_TO_SPEECH/
│
├── main.py
├── tts_engine.py
├── config.py
├── requirements.txt
└── speech.mp3
```

---

## ⚙️ Installation

Install required packages using:

```bash
pip install gtts
pip install playsound==1.2.2
```

OR

```bash
pip install -r requirements.txt
```

---

## ▶️ How To Run

Run the project using:

```bash
python main.py
```
